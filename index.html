Artikel-Regeln

Nutz diese Regeln als Orientierung. Sie helfen oft, aber Ausnahmen bleiben häufig.

der

50%

  • Endungen: -ig, -ich, -ing, -ling, -ismus
  • Zeitwörter: der Montag, der Mai, der Winter
  • Verb-Stämme: der Lauf, der Fall, der Schlaf
  • Wetter / Richtungen: der Regen, der Wind, der Norden
die

25%

  • Endungen: -heit, -keit, -ung, -schaft, -ion, -tät, -ik, -ei, -ur
  • Oft auch -e, aber mit vielen Ausnahmen: der Name, der Glaube, der Gedanke, der Friede
  • Typische Gruppen: die Rose, die Zahl, die Lehrerin
das

25%

  • Endungen: -chen, -lein, -ment, -um, -ma, -nis
  • Ge- + Stamm: das Gebäude, das Gespräch, das Getränk
  • Sprachen / Farben / Verben als Nomen: das Deutsch, das Blau, das Essen
  • Junge Lebewesen: das Kind, das Baby

Verb zu Nomen

Fünf Muster für Nominalisierungen mit Beispielen.

Infinitive

Infinitiv wird großgeschrieben.
Artikel meist: das.

  • arbeiten -> das Arbeiten
  • essen -> das Essen
  • lernen -> das Lernen
  • lesen -> das Lesen
  • reisen -> das Reisen
  • schlagen -> das Schlagen
  • schreiben -> das Schreiben
  • sprechen -> das Sprechen
  • warten -> das Warten
  • ziehen -> das Ziehen

Stamm

Der Stamm wird zum Nomen.
Kein Suffix, oft der.

  • fallen -> der Fall
  • greifen -> der Griff
  • kaufen -> der Kauf
  • laufen -> der Lauf
  • rufen -> der Ruf
  • schlafen -> der Schlaf
  • schlagen -> der Schlag
  • springen -> der Sprung
  • stehen -> der Stand
  • stoßen -> der Stoß

Ablaut

Der Stammvokal wechselt.
Oft bei starken Verben.

  • binden -> der Bund
  • finden -> der Fund
  • fliegen -> der Flug
  • gießen -> der Guss
  • singen -> der Sang
  • sprechen -> der Spruch
  • trinken -> der Trank
  • werfen -> der Wurf
  • ziehen -> der Zug
  • zwingen -> der Zwang

Suffix

Suffixe bilden neue Nomen.
Typisch: -ung, -er, -nis.

  • bedeuten -> die Bedeutung
  • erkennen -> die Erkenntnis
  • erleben -> das Erlebnis
  • führen -> die Führung
  • leiten -> der Leiter
  • schlagen -> die Schlägerei
  • schreiben -> der Schreiber
  • schreiben -> die Schreibung
  • wandern -> die Wanderung
  • ziehen -> die Ziehung

Ge-Präfix

Ge- + Stamm + -e.
Oft wiederholt oder störend.

  • fragen -> das Gefrage
  • husten -> das Gehuste
  • laufen -> das Gelaufe
  • reden -> das Gerede
  • rufen -> das Gerufe
  • schlagen -> das Geschlage
  • schreiben -> das Geschreibe
  • singen -> das Gesinge
  • tanzen -> das Getanze
  • ziehen -> das Geziehe

Kasus und Artikel steuern sie.

  • bekannt -> ein Bekannter
  • deutsch -> ein Deutscher
  • gut -> das Gute
  • krank -> die Kranke
  • neu -> etwas Neues
  • reich -> die Reichen

  • wichtig -> das Wichtigste
