Artikel-Regeln

Nutz diese Regeln als Orientierung. Sie helfen oft, aber Ausnahmen bleiben häufig.

der

50%

  • Endungen: -ig, -ich, -ing, -ling, -ismus
  • Zeitwörter: der Montag, der Mai, der Winter
  • Verb-Stämme: der Lauf, der Fall, der Schlaf
  • Wetter / Richtungen: der Regen, der Wind, der Norden
die

25%

  • Endungen: -heit, -keit, -ung, -schaft, -ion, -tät, -ik, -ei, -ur
  • Oft auch -e, aber mit vielen Ausnahmen: der Name, der Glaube, der Gedanke, der Friede
  • Typische Gruppen: die Rose, die Zahl, die Lehrerin
das

25%

  • Endungen: -chen, -lein, -ment, -um, -ma, -nis
  • Ge- + Stamm: das Gebäude, das Gespräch, das Getränk
  • Sprachen / Farben / Verben als Nomen: das Deutsch, das Blau, das Essen
  • Junge Lebewesen: das Kind, das Baby

Fünf Muster für Nominalisierungen mit Beispielen.

Infinitive

Infinitiv wird großgeschrieben.
Artikel meist: das.

  • arbeiten -> das Arbeiten
  • essen -> das Essen
  • lernen -> das Lernen
  • lesen -> das Lesen
  • reisen -> das Reisen
  • schlagen -> das Schlagen
  • schreiben -> das Schreiben
  • sprechen -> das Sprechen
  • warten -> das Warten
  • ziehen -> das Ziehen

Stamm

Der Stamm wird zum Nomen.
Kein Suffix, oft der.

  • beginnen -> der Beginn
  • besuchen -> der Besuch
  • danken -> der Dank
  • fallen -> der Fall
  • kaufen -> der Kauf
  • laufen -> der Lauf
  • rufen -> der Ruf
  • schlafen -> der Schlaf
  • schlagen -> der Schlag
  • stoßen -> der Stoß

Ablaut

Der Stammvokal wechselt.
Oft bei starken Verben.

  • binden -> der Bund
  • finden -> der Fund
  • fliegen -> der Flug
  • gießen -> der Guss
  • singen -> der Sang
  • sprechen -> der Spruch
  • trinken -> der Trank
  • werfen -> der Wurf
  • ziehen -> der Zug
  • zwingen -> der Zwang

Suffix

Suffixe bilden neue Nomen.
Typisch: -ung, -er, -nis.

  • bedeuten -> die Bedeutung
  • erkennen -> die Erkenntnis
  • erleben -> das Erlebnis
  • führen -> die Führung
  • leiten -> der Leiter
  • schlagen -> die Schlägerei
  • schreiben -> der Schreiber
  • schreiben -> die Schreibung
  • wandern -> die Wanderung
  • ziehen -> die Ziehung

Ge-Präfix

Ge- + Stamm + -e.
Oft wiederholt oder störend.

  • fragen -> das Gefrage
  • husten -> das Gehuste
  • laufen -> das Gelaufe
  • reden -> das Gerede
  • rufen -> das Gerufe
  • schlagen -> das Geschlage
  • schreiben -> das Geschreibe
  • singen -> das Gesinge
  • tanzen -> das Getanze
  • ziehen -> das Geziehe

Fünf Muster für substantivierte Adjektive mit Beispielen.

Grundregel

Die Endung folgt weiterhin der Adjektivdeklination.
Kasus und Artikel steuern sie.

  • alt -> der Alte
  • alt -> den Alten
  • bekannt -> ein Bekannter
  • deutsch -> ein Deutscher
  • gut -> das Gute
  • krank -> die Kranke
  • neu -> etwas Neues
  • reich -> die Reichen
  • schön -> das Schöne
  • wichtig -> das Wichtigste

Personen

der oder die meint Personen.
Maskulin oder feminin konkret.

  • alt -> der Alte
  • arm -> die Arme
  • bekannt -> der Bekannte
  • deutsch -> die Deutsche
  • fremd -> der Fremde
  • krank -> die Kranke
  • neu -> der Neue
  • reich -> der Reiche
  • schuldig -> die Schuldige
  • verletzt -> der Verletzte

Konzepte

das meint Eigenschaften.
Dinge oder abstrakte Ideen.

  • alt -> das Alte
  • böse -> das Böse
  • falsch -> das Falsche
  • gut -> das Gute
  • möglich -> das Mögliche
  • neu -> das Neue
  • richtig -> das Richtige
  • schön -> das Schöne
  • wahr -> das Wahre
  • wichtig -> das Wichtigste

Signalwörter

etwas, nichts, viel, wenig: -es.
alles: -e.

  • alt -> etwas Altes
  • gut -> alles Gute
  • interessant -> viel Interessantes
  • neu -> etwas Neues
  • neu -> alles Neue
  • schlecht -> nichts Schlechtes
  • schön -> viel Schönes
  • wichtig -> etwas Wichtiges
  • wichtig -> alles Wichtige
  • wissenswert -> wenig Wissenswertes

Farben und Sprachen

Feste neutrale Nomen.
Normalerweise ohne Plural.

  • blau -> das Blau
  • deutsch -> das Deutsch
  • englisch -> das Englisch
  • französisch -> das Französisch
  • gelb -> das Gelb
  • grün -> das Grün
  • rot -> das Rot
  • schwarz -> das Schwarz
  • spanisch -> das Spanisch
  • weiß -> das Weiß
